# 农药标签实验主持人指南

> 仅限实验主持人使用，不向参与者展示。不得向参与者展示标准答案、评分边界或标签条件名称。所有产品与药液均为实验模拟材料。

## 1. 实验结构

- 每位参与者完成 3 个 Block。
- 每个 Block 对应一个产品和一种标签条件。
- 每个 Block 固定顺序：T1 → T2 → T3 → T4。
- 三种标签条件：Original、Enhanced Static、Dynamic。
- 核心原则：统一话术、不提示答案、一次只展示当前任务。
- 配药容器不设规定容量或桶数；记录参与者选择，但不按容器选择计分。

本指南负责统一实验实施，不替代知情同意文件、招募材料或研究者答案册。正式实验前，应完成伦理审批要求、主持人培训、设备测试和小规模预试。

## 2. 主持人的四条底线

1. 只读统一话术；可以原句重复，但不自行解释标签、术语、计算或题意。
2. 不确认答案是否正确，不指向标签位置，不替参与者点击动态标签或选择工具。
3. 同一环节对所有参与者使用相同材料、摆放方式、计时口径和追问规则。
4. 遇到设备故障、液体洒漏或参与者不适时，先暂停计时并处理安全问题，再记录中断。

## 3. 会前准备

### 3.1 研究日开始前检查

- [ ] 确认参与者编号、G1-G6 分组顺序和预约时间；任务材料只写编号，不写姓名。
- [ ] 按 Block 分装：正确标签、对应产品 T1 页、T2 四张卡、T3 提示卡、T4 情境卡、两页记录表。
- [ ] 检查 Original 与 Enhanced 打印清晰。
- [ ] 检查 Dynamic 设备电量、网络或离线版本、触控与日志功能。
- [ ] 将 Dynamic 恢复到统一首页，清除上一位参与者留下的页面、搜索结果、弹窗和输入。
- [ ] 核对每套 T2 有 4 张真实图片卡和 3 张分类区标题卡。
- [ ] 核对 T3 模拟药瓶、有色水、清水、托盘、毛巾、搅拌工具、漏斗和量具；严禁放入真实农药。
- [ ] 提供同样的一组可选容器，位置和朝向一致；不标记推荐容器。
- [ ] 准备独立计时器；只有在参与者已经同意时才启用录音或录像。
- [ ] 将研究者答案册放在参与者看不到的位置，评分在参与者离场后完成。

### 3.2 桌面标准布局

| 区域 | 摆放内容 | 控制要求 |
|---|---|---|
| 参与者正前方 | 当前标签和当前任务材料 | 一次只出现一个任务；上一任务材料及时收回 |
| 参与者侧前方 | 计量工具和可选容器 | 所有人数量、位置和朝向一致 |
| 主持人一侧 | 记录表、计时器、备用材料 | 答案册遮挡；答题时不现场打分 |
| 操作区 | 防水托盘、清水、模拟药液和清洁用品 | 保持干燥；每个 Block 后完全复位 |

## 4. 分组与 Block 顺序

| 组别 | Block 1 | Block 2 | Block 3 |
|---|---|---|---|
| G1 | A-Original | B-Enhanced | C-Dynamic |
| G2 | B-Dynamic | C-Original | A-Enhanced |
| G3 | C-Enhanced | A-Dynamic | B-Original |
| G4 | C-Dynamic | B-Enhanced | A-Original |
| G5 | A-Enhanced | C-Original | B-Dynamic |
| G6 | B-Original | A-Dynamic | C-Enhanced |

条件代码：O = Original；E = Enhanced Static；D = Dynamic。

参与者到达后：

- [ ] 核对身份后，只在实验材料上写参与者编号。
- [ ] 按批准流程完成知情同意。
- [ ] 若允许并已同意录音或录像，告知设备已启动；未同意则关闭。
- [ ] 填写组别和三个 Block 顺序，核对每个产品与条件只出现一次。
- [ ] 发放参与者说明并逐字宣读，完成四项理解确认。

不要把标签条件说成“普通版”“更好版”或“智能版”，也不要评价任何版本。对参与者只说“当前标签”。

## 5. 单个 Block 的标准流程与计时

| 阶段 | 主持人操作 | 计时开始 | 计时停止 |
|---|---|---|---|
| 标签呈现 | 展示指定标签，说明可全程查看 | 不单独计时 | - |
| T1 判断 | 发放 5 题判断页，不逐题解释 | 读完 T1 指令并示意开始 | 最后一题落笔或明确口答 |
| T2 分类 | 摆好 3 个区域和 4 张卡 | 读完 T2 指令，手离开材料 | 参与者说完成或停止移动 |
| T3 配药 | 发任务卡，只处理必要的容器交接 | 读完 T3 指令 | 参与者说准备完成 |
| T4 调整 | 紧接 T3 发情境卡 | 读完情境和问题 | 给出最终方案和理由 |
| Block 重置 | 收回全部材料并恢复桌面 | 不计入任务时间 | 复位完成 |

### 统一 Block 开场（逐字读取）

> 下面开始新一轮。你会看到一个产品和一份当前标签。接下来的四个任务都根据这份标签完成。整个过程中都可以继续查看标签。每道题中没有特别提到的情况，都可以认为符合正常使用条件。

### 时间记录规则

- 不催促、不报剩余时间。
- 如果正式方案设置时限，应在预试后锁定，并对所有参与者一致。
- 主持人造成的等待、设备修复或取放重物时间单独记为“实验中断”，不混入主动作答时间。
- 参与者边操作边说话时继续计时；参与者确认最终答案或方案后停止。
- 漏记时间时不要估算，记为缺失并说明原因。

## 6. 允许的话术与禁止提示

| 参与者情况 | 主持人统一回应 |
|---|---|
| 要求重复题目 | 我可以把刚才的原话再读一遍。 |
| 询问答案是否正确 | 我现在不能告诉你对错，请按你的判断完成。 |
| 不知道怎么办 | 请根据当前标签和桌面材料，按你认为合适的方式完成；不确定时可以明确说不确定。 |
| 询问标签术语含义 | 这个任务需要你按照自己对当前标签的理解判断，我不能补充解释。 |
| 询问容器是否正确 | 容器大小和数量没有规定，请自行选择；我不能评价你的选择。 |
| 要求计算帮助 | 我不能帮助计算。你可以继续查看标签，并用桌面上的工具完成。 |
| 需要暂停 | 可以，我们先暂停。准备好继续时请告诉我。 |

不得：

- 指向、圈出或翻到答案位置，用语气、表情或停顿暗示正误。
- 解释“有机磷”“含铜制剂”“碱性药剂”等类别，或替参与者判断图片卡。
- 提示总水量、药量、最高剂量、计算公式、正确工具或操作顺序。
- 为 Dynamic 演示搜索路径、替参与者点击，或只在某一条件下主动介绍功能。
- 在 T4 前评价 T3 方案，或提醒参与者注意某个情境限制。

每次求助都记录任务、原始问题和主持人回应。技术故障与内容求助分开编码。

## 7. T1 判断任务

### 逐字读取

> 下面有 5 句话。请根据当前标签，逐题选择“对”“错”或“不确定”。每题只根据题目明确写出的情况判断；没有提到的情况都认为符合正常使用条件。完成后告诉我。

1. 发放与当前产品对应的一页 T1，不同时发其他产品题目。
2. 开始计时；观察标签回看，但不要盯住参与者视线位置。
3. 如有漏题，只说“请确认每题都有一个选择”，不指出答案。
4. 停止计时并立即收回题页，不当场核对或讨论。

## 8. T2 混配分类

### 逐字读取

> 现在有 4 张其他产品卡。请只根据当前标签，把它们分别放到“明确不能混用”“标签未发现明确禁忌”或“不确定”三个区域。可以移动和修改，确定后告诉我。

1. 三个分类区从左到右固定摆放；四张卡按卡号顺序正面朝上。
2. 读完指令后手离开材料并开始计时。
3. 记录最终位置；如方案需要，可另记首次放置和修改次数。
4. 停止计时，记录最终布局，收回全部卡片并核对 4 张齐全。

“标签未发现明确禁忌”只是一种实验分类，不代表现实农业中一定可以混用。主持人不得把它解释成“安全”。

## 9. T3 实际配药任务

### 逐字读取

> 现在需要为 1 亩地配制一次喷施需要的药液。请根据当前标签，使用桌面上的东西完成配药。容器大小和数量没有规定，请你自己决定水量、药量、量取工具和配药顺序；可以分一桶或多桶完成。准备好后告诉我。

1. 确认桌上只有实验模拟液，开始计时；不介绍工具用途，也不说任何容量是推荐值。
2. 让参与者自行选择容器、桶数和目标水量。主持人只记录，不判断。
3. 若采用“先选方案、再提供约半水容器”的减负设置，在参与者明确方案后暂停计时；容器交到位后恢复计时。所有参与者必须使用同一设置。
4. 记录每桶水量、药量、量具、计算尝试、标签回看、混合步骤和求助。
5. 参与者说完成后停止计时，先记录最终方案，再进行 T4；不要评价 T3。

正式实验前必须锁定“全水量操作”或“统一减负模拟”中的一种，不得因参与者不同临时改变。

### 安全与异常

| 情况 | 处理 |
|---|---|
| 液体洒出 | 立即暂停；请参与者后退，由主持人处理并记录中断 |
| 接触眼口或明显不适 | 立即停止任务并按场地安全预案处理 |
| 参与者想品尝或闻液体 | 立即制止，说明材料不得入口或靠近面部 |
| 容器过重 | 主持人可协助搬动，但不替参与者决定水量或配方；记录协助 |
| 材料用尽或量具损坏 | 暂停，更换同规格材料，记录设备中断后继续 |

## 10. T4 情境调整

### 逐字读取

> 刚才是一般情况下的配药。现在再告诉你一个情况。请看这张卡。知道这个情况以后，你这一次准备怎么用？请把最终方案和理由说完整。

1. 保持同一标签可见，不评价 T3；发放当前产品的 T4 情境卡。
2. 逐字读卡片和问题并开始计时。回答不完整时，只能追问一次：“请把最终方案说完整，包括是否改变、准备怎么用以及理由。”
3. 记录是否继续使用、最终浓度或总量、调整方向、理由、标签回看和信心；不现场评分。
4. 参与者确认最终方案后停止计时，收回材料并结束当前 Block。

## 11. Dynamic 条件的额外控制

- 每个 Dynamic Block 从相同首页和默认状态开始；主持人不主动介绍页面结构或功能。
- 内容求助使用统一中性话术；只有无法点击、页面崩溃、设备断电等技术故障可以介入。
- 技术介入时暂停计时，记录故障类型、持续时间和主持人动作。
- Block 结束后，在批准并已告知的情况下导出日志，再清除输入和浏览状态。

## 12. 偏差与停止规则

| 事件 | 是否继续 | 记录方式 |
|---|---|---|
| 发错产品、标签或卡片 | 停止该 Block | 记重大偏差，由负责人决定重做或剔除 |
| 主持人无意提示答案 | 完成当前任务后评估 | 逐字记录提示内容、时间点和受影响题目 |
| 参与者主动中止 | 立即停止 | 不追问原因，按同意流程处理已收集数据 |
| 短暂休息 | 可以继续 | 记录开始和结束，休息安排在任务之间 |
| 安全事件或持续不适 | 立即停止 | 按安全与伦理流程上报 |

## 13. 实验结束

### 结束话术（逐字读取）

> 今天的任务已经完成。这些产品、剂量和药液都是为实验制作的模拟材料，不能用于现实农业生产。我们关注的是不同标签怎样帮助人们找到并使用信息，不是在评价你的农业知识或个人能力。现在还有没有想补充的感受或问题？

### 参与者离场后检查

- [ ] 停止录音或录像并确认文件保存；按参与者编号命名。
- [ ] 核对 3 个 Block 的 T1-T4 记录、时间、求助、标签回看和偏差说明。
- [ ] 离场后依据研究者手册评分；无法判断的项目标记待复核。
- [ ] 回收全部卡片和标签，清洗量具、补充模拟液并擦干操作区。
- [ ] 将 Dynamic 恢复首页并清除上一位参与者状态。
- [ ] 纸质与电子材料按批准的数据管理方案保存。

### 每个 Block 结束 30 秒检查

- [ ] T1：5 题完整。
- [ ] T2：4 张卡的最终位置已记录。
- [ ] T3：最终水量、药量、工具和步骤已记录。
- [ ] T4：最终方案和理由已记录。
